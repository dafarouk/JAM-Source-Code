JAM {{VERSION}} - Job Application Manager - By Farouk
====================================================

WINDOWS INSTALLATION
--------------------
1. Extract the downloaded ZIP file.
2. Double-click JAM-Setup-{{VERSION}}.exe.
3. Choose English or French when Setup starts.
4. Follow the installer and keep the shortcuts/file association you want.
5. Launch JAM from the Desktop or Start Menu.

WINDOWS SECURITY NOTICE
-----------------------
JAM is distributed without a paid Windows code-signing certificate.
Windows SmartScreen may therefore show an unknown publisher warning.
Download JAM only from the official GitHub repository/release.

LOCAL-FIRST
-----------
JAM stores its database, backups, settings and recovery data locally by default.
The multilingual Analyzer is bundled with the Windows release so its semantic
model does not need a large first-use download.

FRANCAIS
--------
1. Extrayez le fichier ZIP téléchargé.
2. Lancez JAM-Setup-{{VERSION}}.exe.
3. Choisissez Français ou English au démarrage de l'installation.
4. Suivez l'assistant et gardez les raccourcis/association .jam souhaités.
5. Lancez JAM depuis le Bureau ou le menu Démarrer.

JAM est distribué sans certificat payant de signature Windows. SmartScreen peut
donc afficher un avertissement d'éditeur inconnu. Téléchargez JAM uniquement
depuis le dépôt ou la release GitHub officielle.
