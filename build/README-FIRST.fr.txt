JAM - Job Application Manager
Par Farouk

JAM est une application Windows gratuite et local-first pour organiser vos
candidatures, suivre les entretiens et relances, analyser les offres par rapport
à votre CV et gérer tout votre parcours de candidature depuis une seule app.

Vos données de candidature restent sur cet ordinateur par défaut.

L'installateur peut créer des raccourcis Bureau/Menu Démarrer et associer les
fichiers projet .jam à JAM.

JAM vérifie les nouvelles versions sur la page GitHub Releases officielle.
