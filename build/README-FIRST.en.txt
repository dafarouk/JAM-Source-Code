JAM - Job Application Manager
By Farouk

JAM is a free local-first Windows application for organizing job applications,
tracking interviews and follow-ups, analyzing job descriptions against a CV,
and managing the full application workflow from one place.

Your application data stays on this computer by default.

The installer can create Desktop and Start Menu shortcuts and associate .jam
project files with JAM.

JAM checks the official GitHub Releases page for updates.
